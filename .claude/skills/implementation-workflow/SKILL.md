# Implementation Workflow

## Purpose
Implement issue-scoped work in a disciplined way with minimal token waste.

## When to use
Use this workflow when a plan already exists or the issue scope is clear.

## Workflow
1. Confirm issue scope
2. Inspect only relevant files
3. Implement in small steps
4. Add/update tests
5. Summarize coverage against acceptance criteria
6. Prepare commit and PR details

## Rules
- Do not broaden issue scope
- Keep changes focused
- Prefer small edits over large rewrites
- Explicitly mention what remains unfinished
- Always mention tests added or updated

## Completion checklist
- Code updated
- Tests updated
- Acceptance criteria mapped
- Commit message ready
- PR title ready
