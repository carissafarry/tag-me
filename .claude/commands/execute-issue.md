Execute one issue in a disciplined, test-oriented way.

Arguments:
- Issue ID or issue title

Instructions:
1. Use the Linear issue as source of truth
2. Inspect the relevant files only
3. If no plan exists in the current session, create a minimal implementation plan first
4. Implement only the current issue scope
5. Add or update tests for the acceptance criteria
6. Summarize:
   - files changed
   - acceptance criteria covered
   - tests added/updated
   - remaining work
7. Do not create a PR yet unless explicitly asked
